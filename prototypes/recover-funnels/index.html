Which funnel is the better experience?

Heuristic comparison from the Figma flows, not user-tested. Use the scenarios above to feel the difference, and the live tap/screen counters to measure it.

CriterionFunnel 1Funnel 2
Returning user, different numberContinue → "couldn't find" error → Find my account → Send code. 3 taps, but the user types a number that fails and hits an error first.Find my account → Use email → Send code. 3 taps, no failed lookup and no number to type.
User who signed up with AppleUse email → "I signed up with Apple" (2 taps), but Apple is a small link on a different screen than the primary path.Find my account → I signed up with Apple (2 taps), shown as a peer option.
New user, no accountContinue → fail screen → Create new account. One clear decision point.Same path, but the extra "Find my account" link on the first screen competes with Continue and can send a new user down a recovery path (the "one more click" risk noted in the file).
Dead endsFail screen offers Find / Create / Edit number. Good safety net.Recovery choice screen has no "Create account" exit except Back. Weaker for a confused new user.
Method choiceEmail first, Apple hidden in a link; recovery methods are discovered one at a time.Email, Apple and "find with info" shown together, so the user picks the one that matches their memory.
Screen count on the recovery pathOnboarding, error, email, verify, welcome back, doneOnboarding, choose method, email, verify, welcome back, done (same length; the error screen is replaced by a choice screen)
Recommendation: Funnel 2, with Funnel 1's safety net. Tap counts are about equal, so the gain is quality, not speed: recovery users skip a failed lookup and an error message, and see every recovery method up front. Keep the "couldn't find account" screen (with Create new account) for anyone who does type a number that doesn't match, and add a "Create new account" link to the Funnel 2 choice screen so it is not a dead end. To protect new-user conversion, soften the entry link (for example "Already have an account? Find it") and A/B test sign-up completion rate against Funnel 1.
